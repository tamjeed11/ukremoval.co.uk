How to set this up

  1. Open script.google.com and open your existing project
  2. Replace the file contents with the new google-apps-script.gs provided
  3. Create a Google Sheet name the first tab Posts
  4. Copy the Sheet ID from its URL and paste it into the script where it says SHEET_ID
  5. Click Deploy → New Deployment → Web App
  6. Set Execute as: Me and Who has access: Anyone → Deploy → Authorize
  7. Copy the Web App URL and paste it above
  8. Click Test Connection you should see "Connected ✓"

After this one-time setup, every post you save here goes live on your blog automatically.
